# Password-Strength-Checker
A mini Python project that checks password strength by validating length, digits, uppercase letters, lowercase letters, and special characters to improve password security.

# 🔒 Password Strength Checker

## Overview

This is a Python-based Password Strength Checker that evaluates the strength of a password using different security rules.

## Features

* Checks minimum password length (8 characters)
* Verifies the presence of at least one digit
* Verifies the presence of at least one uppercase letter
* Verifies the presence of at least one lowercase letter
* Verifies the presence of at least one special character
* User-friendly command-line interface

## Technologies Used

* Python
* Regular Expressions (Regex)

## How to Run

1. Clone the repository
2. Open the project folder
3. Run the following command:

```bash
python password_checker.py
```
